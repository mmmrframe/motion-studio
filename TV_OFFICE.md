# Ролик на ТВ в офис

Тип заявки в форме Motion Studio (вкладка **Ролик на ТВ**, прямая ссылка — `…/motion-studio/#tv`).
Логика повествования берётся из презентации продукта: **каждый слайд — отдельная сцена в AE**. Сейчас готова структура заявки и JSON. Скрипт для AE напишем, когда будет XML проекта с анимацией.

## Сцены
| Сцена | Слайд | Что внутри |
|---|---|---|
| `S01_TITLE` | титульный | логотип Solar, название продукта, описание |
| `S02_FEATURES` | «Что делает продукт» | заголовок, подзаголовок, 4 карточки 2×2 (номер, заголовок, текст) |
| `S03_ADV_01`, `S04_ADV_02`, … | «Преимущества» | общий заголовок и подзаголовок, **2 блока на экран** |

Блоки преимуществ добавляются **парой** («＋ Добавить экран (2 блока)»): каждая пара — новый экран, то есть новая сцена. Нумерация блоков сквозная (01–02, 03–04, 05–06…). Экраны можно переставлять и удалять, но минимум один должен остаться.

## Лимиты (по текстам и размерам презентации)
| Поле | Макс. знаков |
|---|---|
| Название продукта | 30 |
| Описание (титул) | 300 |
| Заголовок сцены | 40 |
| Подзаголовок | 110 |
| Карточка «Что делает»: заголовок / текст | 50 / 110 |
| Блок преимуществ: заголовок / текст | 75 / 300 |

Кроме лимитов, форма рисует каждую сцену в кадре 1920×1080 с размерами слайда (Arial, кегли из презентации ×2) и проверяет, что текст влезает в карточку. Если не влезает — пишет, в какой сцене и в каком блоке, и кнопка «Дальше» не активна.

## Импорт презентации
Кнопка «Загрузить презентацию .pptx» читает файл прямо в браузере (библиотека JSZip лежит в `web/vendor/`):
- слайд без нумерованных карточек → титул (крупный текст — название, следующий — описание);
- слайд с 3–4 карточками → «Что делает продукт»;
- слайды с карточками дальше → блоки преимуществ, по 2 на экран.

Карточка — это номер (`01`, `02`…) и тексты под ним или справа от него: самый крупный — заголовок, остальное — текст. После импорта тексты нужно проверить. Проверено на «Solar AI Firewall.pptx»: 4 слайда → титул, 4 карточки, 4 блока.

## Тайминг
По умолчанию: титул 7 с, «Что делает» 14 с, каждый экран преимуществ 10 с. Длительность каждой сцены меняется на шаге «Тайминг» (2–60 с). Ролик — 1920×1080, 25 fps.

## JSON заявки
```json
{
  "type": "tv_office", "version": 1,
  "format": { "width": 1920, "height": 1080, "fps": 25 },
  "product": "Solar AI Firewall",
  "scenes": [
    { "id": "S01_TITLE", "kind": "title", "start": 0, "duration": 7, "title": "…", "description": "…" },
    { "id": "S02_FEATURES", "kind": "features", "start": 7, "duration": 14, "heading": "…", "subheading": "…",
      "cards": [ { "n": "01", "title": "…", "text": "…" }, … ] },
    { "id": "S03_ADV_01", "kind": "advantages", "start": 21, "duration": 10, "heading": "…", "subheading": "…",
      "cards": [ { "n": "01", "title": "…", "text": "…" }, { "n": "02", "title": "…", "text": "…" } ] }
  ],
  "total": 41
}
```
Через пайплайн GitHub такая заявка приходит задачей с меткой `tv-office`, JSON лежит в её описании.

## Дальше
1. XML проекта с анимацией: имена композиций сцен, текстовые слои, тайминги появления.
2. Скрипт `web/ae/tv_office_apply.jsx`: по JSON подставляет тексты в сцены, дублирует сцену преимуществ на каждую пару блоков, расставляет сцены в главной композиции по `start` / `duration`.
3. Превью сцен — один в один с проектом AE, как для DDoS priglos 16:9.
